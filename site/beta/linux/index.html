DoveLoFanno su Linux e altri NAS con Docker

Per mini-PC, Raspberry Pi 4 o 5, server di casa, Unraid, TrueNAS, OpenMediaVault: ovunque ci sia Docker. DoveLoFanno gira in un container e tiene tutti i suoi dati in una cartella.

  • Tempo: circa 15 minuti
  • Difficoltà: serve un po' di pratica col terminale
  • Serve: Docker con docker compose

Mai usato un terminale? Allora è più semplice un PC Windows. Se hai un Synology o un QNAP, usa le loro pagine.

Prima di cominciare

Apri un terminale sul server (direttamente o con ssh) e controlla due cose.

  • Il processore: scrivi uname -m. x86_64 → file amd64; aarch64 → file arm64. Se esce armv7l il sistema è a 32 bit e DoveLoFanno non ci gira (su un Raspberry Pi 4 o 5 basta installare Raspberry Pi OS a 64 bit).
  • Docker: scrivi docker compose version. Se risponde con un numero di versione, ci sei. Altrimenti installa Docker seguendo la guida ufficiale per il tuo sistema.

Installa, passo per passo

  1. Carica l'immagine (con arm64 al posto di amd64 se è il tuo caso): 
    docker load -i dovelofanno-0.2.2-docker-amd64.tar.gz
    Loaded image: dovelofanno:0.2.2 dopo qualche decina di secondi.
  2. Crea le cartelle e guarda i numeri del tuo utente: 
    mkdir -p ~/dovelofanno/data ~/dovelofanno/registrazioni
cd ~/dovelofanno
id -u; id -g
    due numeri, spesso 1000 e 1000.
  3. Crea il file compose.yaml: nano compose.yaml, incolla questo testo mettendo nella riga user i due numeri del passo prima, poi salva con Ctrl+O, Invio ed esci con Ctrl+X. 
    services:
  dovelofanno:
    image: dovelofanno:0.2.2
    container_name: dovelofanno
    restart: unless-stopped
    user: "1000:1000"
    ports:
      - "8765:8765"
    volumes:
      - ./data:/data
      - ./registrazioni:/recordings
    environment:
      TZ: Europe/Rome
  4. Avvialo: 
    docker compose up -d
    Container dovelofanno Started. Con docker compose logs -f vedi cosa fa (esci con Ctrl+C, il programma resta acceso).
  5. Aprilo: l'indirizzo del server te lo dice hostname -I (il primo numero). Nel browser di un altro computer scrivi http://indirizzo:8765, per esempio http://192.168.1.40:8765. la schermata dei profili di DoveLoFanno.
Vai ai primi passi

Unraid, TrueNAS, OpenMediaVault hanno un loro modo di caricare un'immagine e un file compose: valgono lo stesso file e le stesse due cartelle. Se non trovi la strada, scrivimi.

Se qualcosa non va

  • Il container si ferma subito con «permission denied». I numeri della riga user non sono quelli del proprietario delle cartelle: controlla con ls -ln ~/dovelofanno.
  • Dagli altri computer non si apre. Se il server ha un firewall attivo, apri la porta: con ufw sudo ufw allow 8765/tcp.
  • exec format error: hai caricato il file dell'altro processore.
  • I log sono in ~/dovelofanno/data/logs e in docker compose logs: mandameli a beta@dovelofanno.it.

Aggiornare e togliere

Aggiornare: scarica e copia il nuovo file, docker load -i come la prima volta, cambia il numero nella riga image di compose.yaml e dalla cartella ~/dovelofanno lancia docker compose up -d. Dati, liste e registrazioni restano.

Togliere: dalla cartella ~/dovelofanno docker compose down, poi docker image rm dovelofanno:0.2.2. La cartella con dati e registrazioni resta finché non la cancelli tu.
